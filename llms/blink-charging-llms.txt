# Blink Charging

> Blink Charging Co. (Nasdaq: BLNK) is a United States electric vehicle charging company headquartered in Bowie, Maryland. It manufactures Level 2 and DC fast chargers, owns and operates charging stations, and runs the Blink Network — the proprietary cloud platform behind its host portal, driver mobile app and fleet management product. Blink publishes NO public API: there is no developer portal, no API reference, no base URL and no machine-readable contract on any Blink host as of 2026-07-27. This file exists so an agent stops looking, and knows exactly what does and does not exist.

## What an agent needs to know first

- There is no Blink developer portal. `developer.blinkcharging.com`, `developers.blinkcharging.com`, `api.blinkcharging.com`, `docs.blinkcharging.com` and `data.blinkcharging.com` do not resolve. `/developers`, `/api`, `/docs`, `/openapi.json`, `/swagger.json` and `/api-docs` on blinkcharging.com return 404.
- Blink's own Terms and Conditions (last modified 2025-12-02) do govern "the Blink API" and tie its use to a username, so an account-credentialed interface exists — but nothing about it is published.
- `https://api.blinknetwork.com` is a live Kong 2.8.1 gateway. Unmatched paths return `{"message":"no Route matched with those values"}`. Every `/map`-prefixed path returns HTTP 503 with: "This service is currently unavailable. Please contact support if you need access to OCPI." That is Blink's OCPI gate, switched off for anonymous callers.
- The retired BlinkMap API developer programme (`prod.blinknetwork.com/developer.html`) is dead — the host refuses connections and the page was last archived 2021-07-28.
- The only live data-request route is a UK open-data Google Form under the Public Charge Point Regulations 2023; requests are human-reviewed and shared with Eco-Movement.
- Do NOT treat the three AE-modeled OpenAPI documents in the sibling repo `all/blink` as Blink contracts. They were reverse-modeled from a January 2014 Blink "API Map" PDF via an unofficial Ruby client and are not provider-published.

## Standards Blink actually adopts (below the API layer)

- [OCPP 2.0.1 certification](https://blinkcharging.com/news/blink-charging-achieves-ocpp-2-0-1-certification-for-ev-chargers): 2025-09-16, Series 7/8/9 chargers. Charger-to-CSMS device protocol, not a developer API.
- [OpenADR 2.0 approval](https://blinkcharging.com/news/blink-network-approved-by-openadr-alliance-allowing-for-advanced-two-way-communication-with-utility-providers): 2020-03-17, the Blink Network. Utility load-management integration, no published endpoint.
- [FedRAMP "In Process"](https://blinkcharging.com/news/blink-charging-achieves-in-process-fedramp-status): 2024-06-13. In Process is not an authorization; no later first-party page announces full authorization.
- OCPI: gated. See the 503 message on `https://api.blinknetwork.com/map/v1`.

## Security and compliance

- [Trust Center](https://trust.blinkcharging.com): Vanta-hosted, live, unlinked from site navigation. Certifications are not readable anonymously (request-signed GraphQL), so none are claimed here.
- No `/.well-known/security.txt` on any Blink host; no published vulnerability disclosure programme.
